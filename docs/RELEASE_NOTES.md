# Halo Steam Frame Setup 1.2.2

Download only **[Halo-Steam-Frame-Setup-1.2.2.exe](https://github.com/ClassicWasTaken/HaloCE-SteamFrame/releases/download/v1.2.2/Halo-Steam-Frame-Setup-1.2.2.exe)**. This is the complete Windows installer; no ZIP, Python installation, or extra installer file is needed.

Version 1.2.2 shows what setup is doing throughout a run and adds **Uninstall Halo VR**. Activity opens automatically with phase updates and live build output. A determinate bar fills from left to right using weighted installation stages, measured upload bytes, and completed Ninja build tasks.

- Progress never moves backward during a run. Package setup, configuration, and other work without a measurable total hold the bar's current value while available log output continues. The percentage describes completed work, not elapsed time or a finish-time estimate.
- A failed or canceled run preserves its reached progress. A remaining manual Steam-library or artwork step stays at 99%; only full success reaches 100%.
- Explicitly closes SFTP and command channels and the underlying SSH transport on completion, failure, or cancellation. The activity feed shows disconnecting and disconnected stages, and full success is reported only after setup disconnects. This does not change the Frame's Wi-Fi or Steam streaming settings.
- **Save log** retains troubleshooting details with credentials redacted. Failure dialogs keep a concise headline and direct users to the activity feed or saved log.
- Clarifies supported game data: original Xbox **USA Rev 2 is validated**. Other retail revisions/regions, including images labeled USA Rev 1, are accepted only when all 24 required version-5 maps share an approved build: `01.10.12.2276` or `01.08.15.1749` (NTSC), or `01.01.14.2342` (PAL), from the [pinned compatibility table](https://github.com/startupfoundry/halo-ce-universal/blob/88142798513ebd99fc7c6224023e8b44c05d0106/source/cache/cache_files.c#L616-L631). Filename Rev labels alone are not validation. PC/Custom Edition, Xbox 360 Anniversary, MCC, and Quest packages remain unsupported.
- **Uninstall Halo VR** needs an SSH connection, but no ISO. It removes only the recognized, owned standard native game folder and its Steam shortcut. **Keep my campaign saves in a backup (recommended)** is checked by default; setup backs up saves inside the native folder and the original config, then reports the backup path. Saves configured outside the native folder, unrelated games/settings, and foreign or unrecognized folders are preserved. The build cache is kept for troubleshooting.
- Uninstall requires closing games and a normal Steam shutdown. Setup stops before deleting the game if Steam cannot close or an owned installation build is still running, and disconnects SSH before reporting successful completion.
- Retains the 1.2.1 rootless build-container permission fix: explicit container root (`--user=0:0`) with ordinary `steamos` host privileges and `no-new-privileges`. Retry reuses an earlier owned map upload only after complete manifest, header, and SHA256 verification, with verification repeated at build and finalization.
- Retains Xbox-style controls, the tutorial head-look fix, safe repairs preserving saves and unrelated settings, and Steam registration retry without rebuilding.
- Retains the original Xbox dashboard UI, Halo CE cover in the installer and Steam, and Master Chief executable icon. Menu music automatically plays from validated local Xbox game data at 12% sample amplitude; the Music ON/OFF button has been removed. No soundtrack is bundled or downloaded, and remote-only repair has no local music preview.

Launch this new EXE and start a run to use the new activity and progress display. An installation already compiling in an older EXE keeps its existing behavior; the new download cannot change that ongoing process. Setup still compiles the pinned native VR source on the Frame.

The **[version 1.2.2 source tag](https://github.com/ClassicWasTaken/HaloCE-SteamFrame/tree/v1.2.2)** contains the corresponding installer source, build scripts, and applicable third-party notices/source, including the LGPL Paramiko dependency. GitHub's generated Source code ZIP is optional for developers. The public release attaches one clearly labeled installer EXE and includes its SHA256 in this release description.

The native ARM64/OpenXR game remains experimental upstream work. Its menu and controllers were previously tested on a Steam Frame; this update and the complete first-install wizard still need fresh-device hardware validation. The ARM64 rootless-container CI check exercises package installation and permissions, not a complete game build or VR session. Steam artwork needs an on-device visual check, and menu music needs a listening check. The executable is unsigned. No game ISO, commercial maps, soundtrack, keys, or game binary is included. Music comes only from the user's local Xbox `ui.map`; compatible native/OpenCE multiplayer is separate from legacy Halo PC/MCC servers.

See the repository README for requirements, SSH steps, controls, sources, and troubleshooting.
