# Halo Steam Frame Setup 1.2.3

Download only **[Halo-Steam-Frame-Setup-1.2.3.exe](https://github.com/ClassicWasTaken/HaloCE-SteamFrame/releases/download/v1.2.3/Halo-Steam-Frame-Setup-1.2.3.exe)**. This is the complete Windows installer; no ZIP, Python installation, or extra installer file is needed.

Version 1.2.3 keeps the Frame's Steam Home and SteamVR session running during setup. It removes automatic Steam shutdown requests and separate Steam launches after a reported 1.2.2 shutdown timeout left the headset's Steam service in a failed restart state. The saved-and-closed-games checkbox now describes closing games only. Setup does not directly edit a running client's library files and reports any remaining manual registration step. See the [session safeguard and diagnostic sources](SOURCES.md#steam-session-safeguard).

- Adds guarded library registration and native shortcut removal through the running Steam client. Setup verifies the exact native executable and launch settings after adding it, and verifies removal before uninstall deletes game files. The client interface is undocumented and version-dependent; unavailable capabilities, ambiguity, timeouts, or unverified results produce manual Add/Remove instructions while Steam Home and SteamVR stay running. If Steam is already closed, the backed-up atomic library-file path remains available.
- Adds missing portrait and landscape Halo CE art through the running client's custom-artwork interface, verifying the active account, native shortcut, and written image hashes. Existing custom artwork is preserved. The installer does not directly write live grid files; unavailable or unverified artwork produces a separate manual step at 99%.
- Retains automatic activity opening, current phases, and live build output. The left-to-right progress bar uses weighted stages, transferred bytes, and completed Ninja tasks and never moves backward during a run. Work without a measurable total holds the reached value while available log output continues. The percentage describes completed work, not elapsed time or a finish-time estimate.
- A failed or canceled run preserves its reached progress. A remaining manual Steam-library or artwork step stays at 99%; only full success reaches 100%.
- Explicitly closes SFTP and command channels and the underlying SSH transport on completion, failure, or cancellation. The activity feed shows disconnecting and disconnected stages, and full success is reported only after setup disconnects. This does not change the Frame's Wi-Fi or Steam streaming settings.
- **Save log** retains troubleshooting details with credentials redacted. Failure dialogs keep a concise headline and direct users to the activity feed or saved log.
- Clarifies supported game data: original Xbox **USA Rev 2 is validated**. Other retail revisions/regions, including images labeled USA Rev 1, are accepted only when all 24 required version-5 maps share an approved build: `01.10.12.2276` or `01.08.15.1749` (NTSC), or `01.01.14.2342` (PAL), from the [pinned compatibility table](https://github.com/startupfoundry/halo-ce-universal/blob/88142798513ebd99fc7c6224023e8b44c05d0106/source/cache/cache_files.c#L616-L631). Filename Rev labels alone are not validation. PC/Custom Edition, Xbox 360 Anniversary, MCC, and Quest packages remain unsupported.
- **Uninstall Halo VR** needs an SSH connection, but no ISO. It removes only the recognized, owned standard native game folder and its Steam shortcut. **Keep my campaign saves in a backup (recommended)** is checked by default; setup backs up saves inside the native folder and the original config, then reports the backup path. Saves configured outside the native folder, unrelated games/settings, and foreign or unrecognized folders are preserved. The build cache is kept for troubleshooting.
- Uninstall requires saved, closed games. Live shortcut removal affects the active Steam account and leaves artwork cleanup to Steam. The already-closed file path handles matching local account entries and removes only installer-hash-matching artwork. If active Steam requires a manual shortcut-removal step, setup keeps the native game files and stops at 99%; an owned installation build still running also stops removal before deletion. Setup does not shut down or relaunch Steam, and disconnects SSH before reporting its result.
- Retains the 1.2.1 rootless build-container permission fix: explicit container root (`--user=0:0`) with ordinary `steamos` host privileges and `no-new-privileges`. Retry reuses an earlier owned map upload only after complete manifest, header, and SHA256 verification, with verification repeated at build and finalization.
- Retains Xbox-style controls, the tutorial head-look fix, safe repairs preserving saves and unrelated settings, and Steam registration retry without rebuilding.
- Retains the original Xbox dashboard UI, Halo CE cover in the installer and Steam, and Master Chief executable icon. Menu music automatically plays from validated local Xbox game data at 12% sample amplitude; the Music ON/OFF button has been removed. No soundtrack is bundled or downloaded, and remote-only repair has no local music preview.

Launch this new EXE and start a run to use the Steam-session safeguard. An installation already compiling in an older EXE keeps its existing behavior; the new download cannot change that ongoing process. This prevention update does not repair a headset Steam session that has already failed. Setup still compiles the pinned native VR source on the Frame.

The **[version 1.2.3 source tag](https://github.com/ClassicWasTaken/HaloCE-SteamFrame/tree/v1.2.3)** contains the corresponding installer source, build scripts, and applicable third-party notices/source, including the LGPL Paramiko dependency. GitHub's generated Source code ZIP is optional for developers. The public release attaches one clearly labeled installer EXE and includes its SHA256 in this release description.

Validation: 297 automated tests passed and 6 were skipped. On an actual Frame, the final 1.2.3 helper removed the native Steam shortcut, created it again, verified its executable/launch/VR/compatibility settings, and added portrait and landscape artwork with exact source-hash readback. A prior check also preserved and verified existing managed art. Steam and VR services stayed active and unchanged throughout, and the game binary was unchanged. The user confirmed Steam Home returned after separate managed-session recovery. This tested shortcut removal, not game uninstall.

The native ARM64/OpenXR game remains experimental upstream work; its menu and controllers were previously tested on a Steam Frame. The complete first-install wizard and full game uninstall still need fresh-device hardware validation. The ARM64 rootless-container CI check exercises package installation and permissions, not a complete game build or VR session. Steam artwork needs an on-device visual check, and menu music needs a listening check. The executable is unsigned. No game ISO, commercial maps, soundtrack, keys, or game binary is included. Music comes only from the user's local Xbox `ui.map`; compatible native/OpenCE multiplayer is separate from legacy Halo PC/MCC servers.
